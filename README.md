My Python program retrieves weather, forecast, and astronomical data from WeatherAPI. It allows the user to check current conditions, forecast data, and provides horse-riding safety indicators when provided the desired location.

The main.py file is the main structure of the program that contains all lines that make the program run. The weather_api.py file contains the functions that retrieve the API data.

Heat index information for safe horse riding is found from the USEF website.
https://www.usef.org/media/press-releases/us-equestrian-competition-update-heat-index
